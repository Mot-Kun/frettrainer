# FretTrainer

A guitar fretboard learning application built with React, TypeScript and Vite.

## Features

- Interactive guitar fretboard
- Select notes by clicking on the fretboard
- More features coming soon

## Technologies

- React
- TypeScript
- Vite
- CSS

## Getting Started

Install dependencies:

```bash
npm install
```

Start the development server:

```bash
npm run dev
```
